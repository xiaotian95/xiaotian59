# 珠海保姆级旅游攻略 · 网页

面向第一次去珠海的游客，做“少踩坑、知道先去哪、路线不浪费、吃住行看得懂”的单页攻略。

## AI 城市攻略生成器

本目录还包含一个输入城市即可自动生成攻略网页的工具。

### 启动生成器

1. 在 `zhuhai-guide` 目录中创建 `.env`，内容为：

   ```bash
   DEEPSEEK_API_KEY=你的密钥
   ```

2. 启动服务：

   ```bash
   node server.mjs
   ```

3. 打开：

   ```text
   http://127.0.0.1:8766/
   ```

### 安全说明

`.env` 已被 `.gitignore` 忽略，不要把 API Key 写进 `generator.js` 或任何前端代码，也不要提交到 GitHub。

## 运行

直接双击 `index.html` 即可查看，也可以本地起一个静态服务：

```bash
python -m http.server 8765
```

然后打开 `http://127.0.0.1:8765/`。

## 文件

- `index.html`：页面结构与正文内容
