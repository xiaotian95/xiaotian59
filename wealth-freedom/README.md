# 自由刻度

一个纯静态的财富自由临界值计算器。核心公式：

```text
财富自由临界值 = 480 × 月生活开销
               + 单孩终身成本 × 孩子数量
               + 健康储备
               + 重大投入
```

其中 `480 = 12 ÷ 2.5%`，2.5% 为“名义投资回报 4.5% − 长期通胀 2.0%”的示例实际收益率。

## 本地运行

直接用浏览器打开 `index.html`，或在当前目录启动任意静态文件服务：

```powershell
python -m http.server 4173
```

然后访问 `http://localhost:4173`。

## 功能

- 理想月生活开销可从 0 元起自由设定，并实时计算孩子、健康储备与重大投入
- 自定义名义回报与通胀率，自动更新财富自由乘数
- 当前资产完成度、差额、永续月现金流与目标构成
- 输入税后月薪与其他收入，自动计算年工资、年度总收入和可投资结余
- 其他收入支持按月或按年折算，并按当前支出与资产复利估算抵达目标的年数
- 三套快速情景、本地参数记忆、一键复制结果
- 响应式布局、键盘焦点与减少动态效果支持

## 说明

本项目仅用于个人财务规划演示，不构成投资建议，也不承诺任何收益率。
