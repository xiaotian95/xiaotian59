# 彩票图片识别中奖

一个本地运行的 Web 工具：拍照上传双色球或超级大乐透彩票图片，自动识别号码，并根据所选开奖日期自动拉取官方开奖号码、核对中奖结果。

## 功能

- 支持双色球（6 红 + 1 蓝）和大乐透（5 前区 + 2 后区）
- 支持单张拍照，也支持一张图片里放多张彩票
- 用火山方舟视觉模型识别彩票号码
- 自动从官方接口获取开奖号码
- 中奖等级自动判断，历史记录保存在当前浏览器

## 启动

```bash
npm start
```

浏览器打开 <http://localhost:8787>。

## 配置火山方舟 Key

二选一：

1. 复制 `.env.example` 为 `.env`，填写 `ARK_API_KEY` 后重启。
2. 启动后在页面右上角“设置”里填写 API Key，本次会话内使用。

## 数据来源

- 双色球：中国福利彩票网官方开奖接口
- 大乐透：中国体育彩票网官方开奖接口

本项目仅用于个人核对娱乐，不构成任何购彩建议。
